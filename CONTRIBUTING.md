# Contributing to microbialites_backend

Thank you for your interest in contributing to this project! Here are the steps to follow:

## Code of Conduct
By contributing, you agree to follow the community guidelines and respect all contributors.

## Contribution Process
1. **Fork the Repository**:
   - Create a personal copy of the repository by clicking "Fork" on GitHub.
2. **Make Changes**:
   - Create a new branch for your changes: `git checkout -b your-feature-branch`
   - Make your updates and commit your changes: `git commit -m "Description of changes"`
3. **Submit a Pull Request (PR)**:
   - Push your branch: `git push origin your-feature-branch`
   - Open a pull request on the main repository, describing your changes in detail.

## Types of Contributions
- Bug fixes
- New features
- Documentation updates
- Code refactoring

## Acknowledgment of Contributions
Your contributions will be listed in the [CONTRIBUTORS.md](https://github.com/Alice-1031/microbialites_backend/blob/main/CONTRIBUTORS.md) file upon approval of your pull request.
